# Travellian

Адаптивный сайт туристического агентства, свёрстанный по макету Figma
«Travellian — Travel Agency Landing Page». Одна страница, пять версий макета:
1920, 1440, 1152, 768 и 320 px.

Технологии: HTML, SCSS (компилируется в CSS), JavaScript без библиотек.

## Запуск

Сборка не нужна: готовый CSS уже лежит в `styles/css/main.css`.

Опубликованная версия: https://weannqww.github.io/travellian/

- Простой способ — открыть `index.html` в браузере. В Chrome страница так открывается полностью. Safari при открытии файла с диска не загружает шрифты (ограничение Safari для `file://`), поэтому для Safari лучше открыть ссылку выше или Live Server.
- Удобнее — расширение Live Server в VS Code: правой кнопкой по `index.html` → «Open with Live Server».

## Компиляция стилей

Нужен Node.js. Один раз установить Sass:

```
npm install
```

Собрать CSS из SCSS:

```
npm run build
```

Пересобирать автоматически при сохранении файлов:

```
npm run watch
```

Команда `build` читает `styles/scss/main.scss` и записывает `styles/css/main.css`.

## Структура проекта

```
index.html            разметка страницы
404.html              страница «не найдено» (GitHub Pages показывает её для неверных адресов)
styles/scss/          исходные стили
  main.scss           подключает все файлы по порядку
  _variables.scss     цвета, шрифты, ширины экранов
  _mixins.scss        миксины: экраны, сброс списков и кнопок
  _base.scss          шрифты, сброс, контейнер, общий вид секций
  _components.scss    кнопка, заголовок секции, стрелки, рейтинг
  _header.scss …      по одному файлу на раздел страницы
  _not-found.scss     страница 404
styles/css/main.css   готовый CSS
scripts/main.js       меню, карусели, слайдер, проверка форм
images/               фотографии (WebP), логотип
images/icons/         иконки (SVG)
fonts/                Playfair Display, Rubik, Mulish (woff2)
```

## Адаптивность

Базовые стили написаны для макета 1440 px, остальные версии — медиазапросами:

| Миксин    | Условие               | Фрейм макета |
|-----------|-----------------------|--------------|
| `wide`    | от 1920 px            | 1920         |
| —         | 1280–1919 px          | 1440         |
| `laptop`  | до 1279 px            | 1152         |
| `tablet`  | до 1023 px            | 768          |
| `mobile`  | до 767 px             | 320          |

## Что работает

- Мобильное меню: открывается по кнопке, закрывается по ссылке, повторному нажатию и клавише Esc.
- Навигация: ссылки меню и подвала плавно прокручивают страницу к разделам.
- Карусели Popular Destinations, Special Offer, Destination Gallery и Traveler’s Experiences: стрелки переставляют карточки по кругу.
- Первый экран: точки и стрелки справа переключают фоновую фотографию.
- Trip Planners: нажатие на фотографию показывает описание этого тура.
- Форма поездки: проверяет направление и даты, выбранная дата показывается в формате макета.
- Кнопка Details в карточке предложения подставляет город в форму поездки.
- Форма подписки: проверяет email.
- Страница 404: белый экран с надписью «404» по центру и простым подвалом.

Формы учебные: данные никуда не отправляются, и сообщения на странице прямо об этом говорят.

## Шрифты и изображения

Шрифты Playfair Display, Rubik и Mulish взяты с Google Fonts (лицензия OFL) и лежат в `fonts/`.
Фотографии, логотип и иконки взяты из макета Figma.
